## 1. 范围与定制

### 1.1 目标

本地 Web 平台，登录后提供三个业务菜单：

1. **工时周报**：导入一段时间工时汇总 Excel → 解析本地列（含任务号、任务类型等）→ 调用 DeepSeek（可配置）汇总为图2 周报结构 → 在线编辑、一键复制富文本 / Markdown。
2. **配置洞察**（原系统参数配置）：导入内部系统参数 Excel → 按物理行落库（保留 Excel 行号；空/重复 `config_key` 均独立行）→ 表格检索过滤 + 详情（含内嵌图片）+ 按模块等分类可视化；支持 AI 整体/多选分析与右侧对话。
3. **系统配置**：AI 模型 / Base URL / API Key；预置管理员账号相关设置（本期仅单用户）。

### 1.2 本期不做

- Worktile / 外部任务系统接入
- 用户注册、多用户权限体系
- 周报按自然周自动切分（只按「本次导入数据」生成一份）
- 配置表导入历史多版本（仅全量覆盖）
- 云端部署、对象存储
- Docker Compose 加 postgres（上云时再做）

### 1.3 技术选型（已确认）

| 层 | 选型 |
|----|------|
| 前端 | Angular **19.2** + **ng-zorro-antd**（Standalone 默认，组件不显式写 `standalone: true`） |
| 后端 | NestJS + **Fastify**（`@nestjs/platform-fastify`） |
| DB | **Prisma + PostgreSQL**（本机 17.11，`DATABASE_URL`）；旧 SQLite 仅备份、不迁业务数据；compose 加 postgres 推迟到上云 |
| AI | DeepSeek（OpenAI 兼容协议）；Key 仅服务端存储 |
| 文件 | 本地磁盘目录（Excel、提取图片） |
| 仓库 | Monorepo：`apps/web` + `apps/api`，目录分离 |

### 1.4 复用决策

| 需求 | 已有能力 | 决策 | 证据 |
|----|------|------|------|
| 业务页面 / 请求层 / 登录 | 无（空仓库） | 新建 Monorepo 与基础能力 | 工作区初始为空；已 `git init -b master` |
| Excel 解析 | 无 | 后端 `exceljs`（需读单元格图片） | 图3 含内嵌图 |
| AI 调用 | 无 | 后端代理 OpenAI 兼容 Chat Completions | Key 不下发前端长期明文 |

## 2. 菜单、路由与权限

### 2.1 信息架构

```
/login                          登录（未登录可访问）
/                               登录后 Layout
  /weekly-report                工时周报
  /system-config-params         配置洞察
  /settings                     系统配置（AI + 账号信息展示）
```

侧栏菜单与路由一一对应；无权限码体系，**登录即可访问全部菜单**（单用户）。

### 2.2 鉴权

- 预置管理员：如 `admin` / 初始密码（首次启动 seed 写入数据库，可在配置页改密，可选本期后做）。
- JWT（或 Session Cookie）；Angular `AuthGuard` 拦截业务路由；HTTP Interceptor 带 Token。
- 不提供注册入口。

## 3. 页面信息架构

### 3.1 登录页

- 用户名 + 密码；登录失败提示；成功进默认页（工时周报）。

### 3.2 工时周报

| 区域 | 内容 |
|------|------|
| 操作区 | 上传 Excel；「生成周报」；展示解析行数/任务数摘要 |
| 预览区 | 按图2 区块渲染可编辑内容（富文本或结构化表单 + Markdown 双模，见实现要点） |
| 导出区 | 一键复制「带格式文本」；一键复制 Markdown |
| AI 状态 | 不可用时对应区块留空，不阻塞已解析数据的手工编辑 |

**周报结构（对齐图2，无版本标签）：**

- 本周完成工作
  - 按任务号聚合：`#任务号` + 需求/任务名称
  - 子项：由备注等汇总的编号列表
  - **开发缺陷和现场缺陷**：由「任务类型」列归入缺陷类的条目
- 本周整体目标达成度 (%)
- 本周工作总结
- 下周工作思路（巨头模仿，对标改进）
- 下周工作计划
- 需协调与帮助

## 4. 模块与任务清单（前端可逐项实现）

### 4.1 工程骨架

- **说明**：初始化 `apps/web`（Angular 19.2 + ng-zorro）、`apps/api`（NestJS）、根 README 本地启动说明；SQLite 文件路径约定。
- **验收**：`web`/`api` 分别能本地启动；健康检查接口可达。

### 4.2 登录与 Layout

- **说明**：登录页、侧栏菜单、路由守卫、Token 持久化。
- **UI要点**：ng-zorro Layout + Menu；三菜单图标区分。
- **验收**：未登录进业务页跳登录；登录后可切换三菜单；刷新保持登录态（在 Token 有效期内）。

### 4.3 工时 Excel 导入与解析预览

- **说明**：上传后调用后端解析；前端展示解析结果摘要（行数、任务号列表）；列名**自动识别**（中英文/近义词映射表可配置扩展）。
- **关键列映射（启发式，可配置别名）**：工作日期、工时、备注、交付项目编号、**任务号**、**任务类型**、需求/任务名称等；无法识别的列进入 `extra` 保留。
- **验收**：导入图1 类文件成功；缺任务号列时明确提示；物理行与解析条数一致。

### 4.4 周报 AI 生成与编辑复制

- **说明**：将解析 JSON + 固定 Prompt/模板发给后端 AI；返回结构化周报；页面可编辑；复制富文本（`ClipboardItem` text/html + text/plain）与 Markdown。
- **校验联动**：无 AI 配置或调用失败 → 目标达成度/总结/思路/协调等 AI 字段为空；任务列表尽量仍可由规则聚合（按任务号合并备注）供编辑。
- **验收**：生成结果区块齐全；编辑后复制内容与所见一致；断网/错误 Key 时不白屏，有错误提示且可手改。

### 4.5 系统参数 Excel 导入

- **说明**：后端按**物理行**入库；`excelRowNo` 必填；`config_key`/`config_name` 允许空；重复 key 多行；全量覆盖前清表（或事务替换）。
- **图片**：提取「前端页面」等相关列单元格锚点图片，存本地并返回可访问 URL。
- **验收**：空 key、重复 key、无 name 有 key 均保留；行号与 Excel 一致；详情能看图。

### 4.6 参数表查询与可视化

- **说明**：主表分页或前端全量（数据量通常百级～千级，可先全量 + 前端过滤）；模糊搜 name/key/注释；模块 Filter；模块分布图（ng-zorro 无图则用简单分组 Collapse 或引入 `@ant-design/charts` 择一，优先轻量分组表）。
- **验收**：过滤/搜索正确；点行开详情见全字段与图。

### 4.7 配置洞察 AI 分析与对话

- **说明**：支持整体分析或勾选单条/多条；请求体带完整行数据（含 raw）；结果展示在左侧（Markdown）；右侧可多轮自由对话（SSE 流式 + Markdown 气泡）。
- **实现要点**：前端统一 `SseClient.postSse`；分析走 `/api/sys-params/analyze/stream`，对话走 `/api/sys-params/chat/stream`。
- **验收**：无选中时「分析选中」不可用；分析报告含整行字段解读；对话可追问并可持续；刷新后分析与对话仍在。

### 4.8 工时周报 AI 对话

- **说明**：周报页左右布局；右侧「ai小助手」基于当前周报多轮对话，SSE 流式 + Markdown。
- **实现要点**：`POST /api/worktime/reports/:id/chat/stream`，经 `SseClient`；本周完成/下周计划支持「原始 / AI 润色」切换。
- **验收**：流式增量可见；失败回填输入并去掉空助手气泡；清空历史可用。

### 4.9 AI 与系统配置页

- **说明**：读写 AI 配置；apiKey 脱敏回显；展示 Token 累计/最近一次用量并可清零。
- **验收**：配置保存后周报/分析可用；刷新后配置与用量仍在。

## 6. 展示规则

### 6.1 工时 → 周报

- **聚合键**：任务号；无任务号的行归入「未关联任务」分组，仍展示备注摘要。
- **标题**：优先需求/任务名称列；否则备注首行截断。
- **缺陷归类**：任务类型列匹配「缺陷 / 开发缺陷 / 现场缺陷」等关键词（别名表可配）→ 进入「开发缺陷和现场缺陷」。
- **不做**：版本号 `【HNOS x.x.x】` 拼接（已确认不需要）。
- **日期**：不按周切割；整份导入数据视为「本周」语境生成。

### 6.2 系统参数表

- **一行 Excel = 一条记录**；不因 key 相同合并。
- **主表建议列**：Excel序号、`config_name`、`config_key`、模块、是否删除类字段（若识别到）、后端服务（若有）、是否有截图。
- **详情**：原始列字典全量展示 + 图片画廊。
- **列名识别**：首行表头；trim；近义词映射（如 `配置键`→`config_key`）；未映射列进 `rawColumns`。

### 6.3 复制

- **带格式**：HTML 列表结构，粘贴到飞书/钉钉/Word 尽量保层级。
- **Markdown**：与图2 层级对应的 md 文本。

## 7. 异常与空状态

| 场景 | 处理 |
|------|------|
| 未登录 | 跳转 `/login` |
| Excel 非 xlsx/损坏 | 错误 Toast，不改库 |
| 缺关键列（周报缺任务号） | 警告可继续或阻断（建议警告 + 仍可生成，未关联任务分组） |
| AI 未配置 / 失败 | 提示；AI 字段空；规则可生成的部分仍给出 |

| 全量覆盖 | 导入成功前用事务；失败回滚保持旧数据 |

## 9. 技术实现要点（深化）

### 9.1 前端

- Standalone（默认）+ 懒加载路由；`provideHttpClient(withInterceptors([authInterceptor]))`。
- 组件约定：业务/布局组件使用外提 `templateUrl` + `styleUrl`（`.html` / `.scss`），类上不写显式 `standalone: true`。
- 状态：页面内字段 + `inject` 服务；不做 NgRx。
- 周报编辑：contenteditable 分区（本周完成 / 下周计划）+「原始 / AI 润色」双视图；复制 HTML + Markdown。
- Markdown：公共 `MdViewComponent`（`marked` + `dompurify`），用于分析报告与助手气泡。
- **SSE**：公共根服务 `apps/web/src/app/shared/sse-client.service.ts`（`SseClient`）
  - 使用 `HttpClient.post`：`observe: 'events'`、`reportProgress: true`、`responseType: 'text'`
  - 解析 `HttpDownloadProgressEvent.partialText` 增量，拆 `data:` JSON 为 `Observable<SseEvent>`
  - Authorization 由拦截器附加，调用方不传 token；取消订阅即中止请求
  - 调用方：配置洞察分析/对话、工时周报对话
- HTTP 基址：`apps/web/src/app/core/api/api-base.ts`（`API_BASE` / `UPLOADS_BASE`）。

### 9.2 后端

- 模块：`Auth` / `Settings` / `Worktime` / `SysParams` / `Ai` / `Storage`。
- Excel：`exceljs` 读行列与 pictures（`workbook.model.media` + 锚点行列）。
- AI：统一 `AiService.chat(messages)`；Prompt 与输出 JSON Schema 固定，便于前端渲染。
- 配置覆盖导入：`DELETE` + `INSERT` 同事务。

### 9.3 目录约定（Monorepo）
